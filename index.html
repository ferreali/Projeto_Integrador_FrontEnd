S20 • ACESSIBILIDADE

Perguntas frequentes

O site funciona no celular?

Sim. O projeto foi construído seguindo uma abordagem Mobile-First.

O projeto possui acessibilidade?

Foram aplicados elementos semânticos, textos alternativos, foco visível, labels e suporte à redução de movimento.

A autenticação é real?

Não. Neste projeto educacional, a autenticação é simulada no navegador com localStorage. Em produção, deve existir um backend seguro.
